# trandeer

알고리즘의 필터 버블에 갇히지 않고, 누구에게나 같은 기준으로 고른 **오늘의 사회 이슈**를 보여 주고, 그 이슈와 이어진 **책**까지 찾아가게 하는 트렌드 포털입니다.

- 공개 주소: https://trandeer.vercel.app
- 부산대학교 문헌정보학과 바이브코딩 공모전 출품작

## 왜 만들었나

포털과 SNS의 추천은 이용자가 이미 관심 있는 주제만 보여 주는 경향이 있습니다. trandeer는 다음 원칙으로 만들었습니다.

1. **개인화하지 않는다.** 모든 사람에게 같은 화면을 보여 줍니다.
2. **선정 기준을 공개한다.** 어떤 검색어로 어떤 기사를 모아 어떻게 셌는지 화면에 밝힙니다.
3. **출처를 항상 보인다.** 모든 기사와 도서는 원문이나 상세 페이지로 연결됩니다.
4. **이슈에서 책으로 잇는다.** 이슈와 관련된 실제 도서를 도서관 정보나루에서 찾아 보여 줍니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 오늘의 이슈 | 최근 12시간 네이버 뉴스 제목에서 고유명사를 뽑아, 「제목에 쓴 언론사 수 × 평소 흔함 보정」 점수로 상위 10개를 고릅니다. 이슈마다 관련 기사(원문 링크)를 보여 줍니다 |
| 선정 기준 공개 | 수집 검색어, 점수 산식, 뺀 단어 목록, 수집한 시간 범위(빈 구간 포함)를 화면에 그대로 보입니다 |
| 워드클라우드 3종 | 뉴스, 도서(예스24 베스트셀러 제목과 책 소개), 둘을 합친 종합 워드클라우드와 공통 키워드 |
| 도서 목록 | 예스24 베스트셀러 100권, 도서관 정보나루 최근 30일 인기 대출 100권 |
| 관련 도서 | 이슈 상세: AI가 책을 제안하고 도서관 정보나루와 예스24에서 실제로 있는 책만 남깁니다. 부산 공공도서관 소장 정보를 붙입니다 |
| AI 도우미 (Gemini) | 화면의 이슈, 기사 제목, 도서 목록으로 답하고 근거 기사 링크를 붙입니다. 이 자료로 답할 수 없는 일반 질문은 AI가 일반 지식으로 답하며, **「이 답은 수집한 자료가 아닌 AI가 작성한 답이므로 반드시 검증이 필요합니다」**를 함께 표시합니다. 답 아래 [관련 도서 찾기]는 AI가 뽑은 검색어를 모두 포함한 책을 도서관 정보나루에서 대출 많은 순으로 찾습니다. 「부산 20대가 많이 빌린 책」처럼 물으면 조건별 인기 대출 목록을 보여 줍니다 |
| 구글 검색어 | Google 트렌드의 한국 인기 급상승 검색어 10개와 관련 기사를 걸러 내지 않고 그대로 보여 줍니다. 언론이 다룬 이슈와 사람들이 찾아본 검색어를 비교하는 용도이며, 오늘의 이슈, 워드클라우드, AI 도우미에는 쓰지 않습니다 |
| 화면 | 탭 4개: 모아보기(워드클라우드, AI 도우미, 공통 키워드) / 오늘의 이슈(이슈, 이슈 상세, 구글 검색어) / 도서(베스트셀러, 인기 대출) / 산정 기준 |
| 오늘의 이슈 기록 | 매일 09시, 21시(한국 시각) 회차의 이슈 상위 10개를 `history/issues.csv`에 남깁니다 |

## 구조

```
GitHub Actions (30분마다)
  build.py ── 네이버 뉴스·예스24·도서관 정보나루·Google 트렌드 수집과 분석 ──> web/data.json
  deploy/make_bundle.py ──> Vercel 배포 (정적 화면 web/ + 서버 함수 api/)
  deploy/record_issues.py ──> history/issues.csv 커밋 (09시·21시 회차)

브라우저 ── web/index.html이 data.json을 읽어 그림
        └─ AI 도우미 질문만 /api/chat, /api/books (서버 함수가 Gemini·정보나루 호출)
```

- 화면은 미리 만든 `data.json`만 읽으므로 방문자가 늘어도 뉴스·도서 API 호출은 늘지 않습니다.
- API 키는 서버(GitHub Actions Secrets, Vercel 환경 변수, 로컬 `.env`)에만 있고 브라우저로 가지 않습니다.

## 로컬에서 실행하기 (Windows)

공개 주소에서 바로 볼 수 있습니다. 로컬 실행은 아래 API 키가 있어야 합니다.

1. Python 3.11을 설치합니다(3.11.9에서 확인).
2. 이 폴더에서 가상 환경을 만들고 패키지를 설치합니다.
   ```
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   ```
3. 이 폴더에 `.env` 파일을 만들고 키를 넣습니다(키 이름만 아래와 같으면 됩니다).
   ```
   NAVER_CLIENT_ID=...
   NAVER_CLIENT_SECRET=...
   YES24_API_KEY=...
   DATA4LIBRARY_API_KEY=...
   GOOGLE_API_KEY=...
   ```
4. `run.bat`을 실행합니다. 데이터를 모아 `web/data.json`을 만든 뒤 http://127.0.0.1:8000 을 엽니다. 창을 닫으면 멈춥니다.

키 없이 화면만 보려면 3번을 건너뛰고 `.venv\Scripts\python serve.py`를 실행한 뒤 http://127.0.0.1:8000 을 엽니다. 제출 파일에 들어 있는 `web/data.json`(2026-11-08 수집)을 보여 주며, AI 도우미와 관련 도서는 키가 없어 동작하지 않습니다.

| 키 | 발급처 | 쓰는 곳 |
|---|---|---|
| `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | NAVER Cloud Platform API HUB (뉴스 검색) | 오늘의 이슈, 뉴스 워드클라우드 |
| `YES24_API_KEY` | 예스24 Open API | 베스트셀러, 도서 워드클라우드, 이슈 관련 도서 확인 |
| `DATA4LIBRARY_API_KEY` | 도서관 정보나루 | 인기 대출, 관련 도서, 부산 소장 도서관 |
| `GOOGLE_API_KEY` | Google AI Studio (Gemini) | AI 도우미, 이슈 관련 도서 제안 |

## 데이터 출처와 이용 조건

- **네이버 뉴스 검색(NAVER Cloud Platform API HUB):** 기사 제목, 링크, 발행 시각만 쓰고 기사 전문은 수집하지 않습니다. 언론사는 원문 주소의 도메인으로 표시합니다.
- **예스24 Open API:** 화면에 출처와 상세 페이지 링크를 표시합니다. 하루 1회 받은 결과만 보관합니다.
- **도서관 정보나루:** 책 표지 이미지(`bookImageURL`)는 AI 입력이 금지되어 받지도 저장하지도 않습니다.
- **Google 트렌드 RSS(`trends.google.com/trending/rss?geo=KR`):** 키 없이 받는 공개 RSS입니다. 공식 API가 아니라 형식이 바뀔 수 있고, 받지 못하면 그 탭에만 안내를 표시합니다. 이미지는 받지 않습니다.
- **Gemini API(무료 등급):** 질문은 Google로 전송되며 제품 개선에 쓰일 수 있어, 입력창에 개인정보를 넣지 말라는 안내를 표시합니다. 한 사람이 1분에 5번까지 질문할 수 있고, 무료 등급의 하루 한도를 넘으면 잠시 답하지 못할 수 있습니다.

## 한계

- 분야 검색어(정치, 경제 등)로 모은 기사라 분야를 정확히 대표하지는 않습니다.
- 뉴스 검색은 검색어마다 최근 1,000건까지만 받을 수 있어, 30분마다 수집해 쌓습니다. 수집이 멈춘 시간은 화면에 「빈 구간」으로 표시됩니다.
- AI 도우미의 일반 질문 답과 관련 도서 검색어는 AI가 만든 것이라 틀릴 수 있습니다. 화면의 책 정보는 모두 API 결과만 씁니다.
